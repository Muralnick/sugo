# ADR-014: Enterprise and legal features

**Status:** Accepted  
**Date:** 2026-10-27  
**Deciders:** project author

## Context

Companies and law firms handle personal and confidential data and need control.

## Decision

Offline anonymization with a local restore map, coverage statistics and review mode; offline mode; hash-chained audit log; reproducible outputs; locked policies; extension allow-lists; forced anonymization of MCP output.

## Alternatives considered

| Alternative | Why not |
|---|---|
| No dedicated features | Excludes a target with clear needs |

## Consequences

- Rule-based recognition to be complemented later by more accurate entity recognition; never claimed to be complete.
